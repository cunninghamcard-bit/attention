# RFC 0003：窗口布局改为 Arc 式

- 状态：草案，待确认 §6 的四个问题
- 日期：2026-11-02
- 范围：`native/plugins/layout`、`native/plugins/workspace`、`native/plugins/slots`、`native/plugins/commandpalette`、`native/plugins/switcher`、`native/plugins/appearance`（设置项）
- 关联文档：[RFC 0001 §5.12](0001-go-native-plugin-browser.md) · [RFC 0002](0002-crychic-ui.md) · [产品线规划](../product.md) · [外观系统](../appearance.md)

## 1. 目标

RFC 0001 §5.12 已经决定视觉不再对照 Obsidian，但窗口骨架仍是 Obsidian 的：最左一列图标栏、左右两个 dock、每个分屏顶上的横排标签栏、带面包屑的标题栏、底部状态栏、「No file is open」空白页。换颜色改不掉这种观感。

这份 RFC 把骨架换成 Arc 浏览器的结构。这也是 [product.md](../product.md) 阶段二要的东西：新标签页是起始页，地址栏统一本地路径、网址和命令，侧栏跟着当前标签走。

## 2. 布局

```
┌──────────────────────┬─────────────────────────────────────────────┐
│ ● ● ●   ◧   ←  →     │ ╭─────────────────────────────────────────╮ │
│ ╭──────────────────╮ │ │                                         │ │
│ │🔒 attention/docs/…│ │ │                                         │ │
│ ╰──────────────────╯ │ │                                         │ │
│                      │ │          内容卡片（当前标签的正文）       │ │
│  ＋ 新标签页          │ │                                         │ │
│ ╭──────────────────╮ │ │                                         │ │
│ │ M↓ Welcome.md  × │ │ │                                         │ │
│ ╰──────────────────╯ │ │                                         │ │
│   M↓ Ideas.md        │ │                                         │ │
│   🌐 mygo docs       │ │                                         │ │
│   ▸ 终端             │ │                                         │ │
│                      │ │                                         │ │
│                      │ │                                         │ │
│ Ln 3, Col 5 · Go     │ │                                         │ │
│ ⚙  ☰ 🗂 🔍 🔖       │ ╰─────────────────────────────────────────╯ │
└──────────────────────┴─────────────────────────────────────────────┘
```

**窗口**

- 窗口底色用主题的 `surface`。侧栏直接画在底色上，没有边框。
- 每个分屏是一张内容卡片：底色是 `background`，四周留 `spacing`，圆角是设置里的 `radius`，加一圈细边框。
- 分屏之间留一道缝，是两张卡片，不画分隔线。

**侧栏**：从上到下五段，宽度可以拖动，可以整体收起（收起后卡片铺满窗口）。

1. 顶行：窗口控制按钮的留位、收起侧栏、后退、前进。后退和前进作用于当前分屏的当前标签。
2. 地址栏：显示当前标签的地址，本地文件显示成 `项目/目录/文件`，网页显示 URL；只读文件前面加一个锁。点击打开 Omnibox（见下）。标签类型的 `Header`、`Actions` 和 `Menu` 都画在这里：
   - 网页标签的 `Header` 本来就是地址输入框加建议弹出层，直接放进这个位置；
   - `Actions`（阅读视图、源码切换）放在地址栏右端；
   - ⋯ 菜单（分屏、复制路径、在访达中显示）也在地址栏右端。
3. 主体：一次显示一个面板，默认是**标签页**面板：
   - 顶部是「＋ 新标签页」，下面是竖排的打开标签，每个标签显示图标和标题；
   - 当前标签是一块高亮卡片，鼠标悬停时显示 ×；
   - 可以拖动排序，也可以拖到内容卡片边上分屏；
   - 有分屏时，按分屏分组，组和组之间加一条细线。
4. 状态行：当前标签类型的 `Status`（光标位置、语言、`Image`）缩成一行灰色小字，放在主体下方。
5. 底栏：
   - 设置齿轮；
   - 面板切换按钮：标签页、文件、搜索、书签和 webview 面板，点哪个主体就换成哪个。这是 Arc Library 的做法：侧栏换内容，不另开一栏。

**Omnibox**：沿用命令面板的机制，新增一个合并模式，同时搜三类东西：文件（快速切换的结果）、网址和网页建议、命令。

- `Ctrl T` 新标签页和 `Ctrl L` 聚焦地址栏打开的就是它；
- `Ctrl O`、`Ctrl P` 仍然是只搜文件或只搜命令的单一模式；
- 选中结果后，在新标签页里打开或在当前标签里打开，规则和浏览器一样。

**起始页**：替代「No file is open」那一页。

- 中间是 Omnibox 的输入框，下面是最近打开的文件和已挂载的项目；
- 文案去掉 Obsidian 的那组快捷操作链接。

## 3. 每个扩展点放在哪

| 现在 | 改成 |
|---|---|
| 图标栏：快速切换、命令面板 | 合并进 Omnibox |
| 图标栏：终端、网页 | Omnibox 里的命令，以及起始页上的「新建终端」「新建网页」 |
| 图标栏：设置 | 侧栏底栏的齿轮 |
| 左 dock：文件、搜索、书签、webview 面板 | 侧栏主体的面板，用底栏切换 |
| 右 dock：反向链接、大纲 | 见 §6 问题 1 |
| 横排标签栏（每个分屏一条） | 删除，标签都在侧栏的标签页面板里 |
| 标题栏：后退、前进 | 侧栏顶行 |
| 标题栏：面包屑 | 地址栏 |
| 标题栏：`Header`、`Actions`、⋯ 菜单 | 地址栏 |
| 状态栏左：挂载的文件夹名 | 删除，地址栏里已经有项目名 |
| 状态栏右：`Status`、Read-only | `Status` 进侧栏状态行，Read-only 变成地址栏的锁 |
| 空白标签页 | 起始页 |
| 底部状态栏本身 | 删除 |

## 4. 接口变化

- **`slots`**
  - 删除 `RibbonItem` / `RegisterRibbon`：现在的五项都已经是命令，按 §3 各有去处；
  - 删除 `StatusItem` / `RegisterStatus`：只有 workspace 自己在用；
  - `Dock` 保留 `Left`、`Right`，`Left` 改叫侧栏面板，`Right` 的去处看 §6 问题 1。
- **`workspace` 注册「标签页」面板**，`Order` 排在文件面板前面。这样侧栏不必为标签另写一套切换逻辑。
- **`layout.json`**：新增 `sidebarPanel`。旧的 `leftPanel`、`rightOpen` 照常读，读不懂的值回退到标签页面板。`session.json` 不变。
- **设置**
  - 删除 `showRibbon`、`showTabBar`、`showViewHeader`，读到旧值就忽略；
  - 保留 `showInlineTitle`。
- **`native/AGENTS.md`**：「Port behaviour from the TS app」改成只管行为，不管窗口结构，窗口结构以本 RFC 为准。
- **RFC 0001 §5.12**：补一句布局见本 RFC。
- **product.md 阶段二**：把起始页、Omnibox、侧栏的描述指到本 RFC。

## 5. 分步实施

每一步单独提交，每一步都能运行。

1. `layout`：画成「侧栏 + 内容卡片」，删掉图标栏和状态栏，侧栏先只放原来左 dock 的面板。
2. `workspace`：注册标签页面板，删掉横排标签栏；标题栏的内容搬进侧栏顶行和地址栏；`Status` 进状态行。
3. Omnibox 合并模式和起始页；接上 `Ctrl T`、`Ctrl L`。
4. 右 dock 按 §6 问题 1 的结论处理。
5. 清掉作废的设置项、`slots` 接口和 Obsidian 文案；同步改 AGENTS.md、RFC 0001 和 product.md。

每一步都要过 gofmt、vet、测试、asl 和 CLI 端到端测试，再截图核对。

## 6. 待确认

1. **反向链接和大纲放哪。**
   - 默认方案：保留成右侧第二张卡片，平时收起，从地址栏 ⋯ 菜单或快捷键打开。
   - 另一种：并入侧栏底栏，和文件、搜索同级，代价是看大纲时就看不到标签列表。
2. **文件树的形态（product.md §3 的 A、B、C）。**
   - 默认方案：先做形态 A，文件面板跟随当前标签所属的项目，只展开当前文件所在的那一层；
   - B 和 C 以后再说。
3. **分屏保留。** Arc 也有 Split View，现有的分屏、拖动分屏、比例保存都不动，只是改画成多张卡片。
4. **状态栏删除。** `Status` 挪到侧栏状态行，侧栏收起时就看不到。
