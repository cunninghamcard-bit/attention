# RFC 0006：基本产品交互：项目、标签、AI 和主题

- 状态：草案（2026-11-09）
- 日期：2026-11-09
- 范围：信息结构和交互。视觉细节等换成 ACard 组件以后再定（RFC 0005）。
- 修改：[RFC 0003](0003-arc-layout.md) 的 §4（标签、项目和文件夹）和 §9（文件夹、固定区和书签）；[RFC 0004](0004-theme-tokens.md) 的界面主题部分由本 RFC §8 取代，编辑器配色部分保留。
- 参考：
  - Zen 浏览器的主题源码 `src/zen/spaces/ZenGradientGenerator.mjs`；
  - Alma 0.4.509 的安装包产物（`~/Projects/alma-ref`，闭源，只参考做法）。
- 延后：gloss 式的批注栏问答、文章导读（Brief）、全文缩略图（Rail），见 §12。

## 1. 要解决的问题

1. 项目只能加、删，不能重命名、排序。添加的入口散在右栏和设置里，移除只能去设置。
2. 右栏的文件树只显示当前标签的项目。要看另一个项目，得先打开它的一个文件。
3. 文件树里不能新建、重命名、删除、移动文件，这些只有 CLI 能做。
4. 侧栏里不同项目的标签混在一起，只能手动建文件夹，或者用「按项目整理」命令一次性分组。
5. 「文件夹」一词指三样东西：挂载的项目、磁盘目录、侧栏的标签文件夹。
6. 打开项目外的文件时，界面上没有任何处理。
7. 主 AI 怎么接进来、推送的原文放在哪里，都没有定。
8. 暗色主题的外壳偏蓝（`#142636` 一类），卡片却是近黑，色偏重。主题系统和 Arc、Zen 这类浏览器不一样。

## 2. 名词

界面文字用英文，下表左列是界面上的叫法。

| 名词 | 是什么 |
|---|---|
| Project | 挂载进来的目录，有名字和主题。存在 `mounts.json`。 |
| Folder | 磁盘上的目录。在文件树里出现，每个目录都有自己的文件夹页（§6.5）。 |
| Tab group | 侧栏里用户手动建的标签分组，可以跨项目。取代 RFC 0003 的「标签文件夹」。 |
| Other | 不属于任何项目的标签所在的分组。 |
| Thread | 和主 AI 的一段对话，显示为一个 Chat 标签。 |

## 3. 侧栏

```
[ attention / native / filetree.go ]      地址栏
  ▸ 📁 RFC 讨论                            Tab group（固定区）
  ─────────
▾ ● attention                    ＋  ⋯     项目行
     📌 RFC 0006                          项目内的固定标签，置顶
     💬 怎么改侧栏                         Chat 标签（线程）
     filetree.go
     layout.go │ view.go                  分屏
▸ ● sglang                       3        折叠时显示标签数
▾ ◌ Other
     🌐 mygo docs
     a.md   ~/Downloads
＋ New tab
```

从上到下：

1. **地址栏**：同 RFC 0003。
2. **固定区**：只放 Tab group，没有 Tab group 时不显示。
3. **项目分组**：每个项目一行项目行，下面是归到它的标签。
4. **Other**：项目外的标签，没有时不显示。
5. **＋ New tab**。

**项目行**

- 显示项目的主色点、名字；折叠时在行尾显示标签数。
- 出现条件：这个项目有打开的标签，或者项目被固定（§5.3）。其余项目在起始页和 Omnibox 里找。
- 点名字：打开这个项目的主页标签（§5.2）。点箭头：折叠或展开。
- 悬停时出现两个按钮：`＋` 在这个项目里新建标签，`⋯` 打开项目菜单（§5.3）。
- 拖动项目行可以改变项目的顺序。顺序存在 `mounts.json`。

**标签行**沿用 RFC 0003 的标签行和分屏行。

## 4. 标签归位

### 4.1 规则

标签自动归到项目下，用户不用手动分组。

| 标签 | 归到 |
|---|---|
| 文件 | 文件所在的项目；项目外的进 Other |
| 网页 | 打开它的那个标签所属的项目：在 attention 的标签里点的链接、为 attention 的线程推送的网页，都归 attention。从起始页或 Omnibox 直接打开的进 Other |
| 终端 | 工作目录所在的项目 |
| Chat（线程） | 线程所属的项目（§7.2） |
| 文件夹页（含项目主页） | 目录所在的项目；项目外的进 Other |
| 新标签页 | 当前所在的项目；在新标签页里打开别的项目的文件后，标签移到那个项目下 |
| 分屏 | 第一张卡片的项目 |

- 标签的项目变了，就自动移过去。比如在新标签页里打开了 sglang 的文件，或者文件被移到另一个项目里。
- 网页在同一个标签里跳转到别的站点，项目不变。

### 4.2 位置

- 新标签插在当前标签的后面。如果当前标签属于别的项目，就插在那个项目分组的最后。
- 拖动可以在同一个项目里调整顺序。拖到别的项目下没有效果，因为项目由内容决定。拖进 Tab group 可以。

### 4.3 固定和 Tab group

- **固定标签**：留在自己的项目下，排在最前面。关掉只是卸载，再点重新加载。取代 RFC 0003 的「固定区」和书签。
- **Tab group**：用户手动建，放在顶部固定区，可以装不同项目的标签，可以重命名、折叠、删除。
  - 标签拖进 Tab group 以后，就不再出现在项目分组里；拖出来就回到项目分组。
  - 删除 Tab group 时，里面的标签回到各自的项目分组。
- `bookmark` CLI 命令改成读写固定标签。

### 4.4 关闭

- 普通标签关掉就从列表移除，可以用「撤销关闭」找回（现有的 `workspace:undo-close-pane`）。
- 项目菜单里的「Close all tabs」关掉这个项目下所有没固定的标签。

## 5. 项目

### 5.1 添加

入口：

- 起始页的「Add project…」；
- Omnibox 的 `Add project…` 命令（现有的 `workspace:add-folder` 改名）；
- 侧栏底栏的 `＋` 菜单；
- 从 Finder 把目录拖进侧栏；
- 打开项目外的文件时，右栏顶部的「Add as project」（§6.3）。

规则：

- 名字默认取目录名。同名时自动加上父目录区分，比如 `docs (attention)`，可以改。
- 不允许嵌套。要添加的目录已经在某个项目里，就提示「已属于项目 X」，不添加。要添加的目录包含了已有的项目，就提示，用户确认后，被包含的项目并进新项目：它的标签归到新项目，颜色丢弃。

### 5.2 项目主页

项目主页就是项目根目录的文件夹页（§6.5）。点项目行的名字打开它，已经开着就切过去。

和其他目录的文件夹页相比，项目根多两样：

- 面包屑下面有一行项目信息：git 分支、未提交的改动数（点开列出改动的文件，只读）、本项目的线程数（点开是线程列表）；
- 顶栏的 `⋯` 是项目菜单（§5.3）。

### 5.3 项目菜单

项目行的 `⋯` 和右键菜单，以及项目主页顶栏的 `⋯`，是同一组操作。项目设置（名字、主题、固定、移除）也在这里：

- Rename：只改显示名，不改目录名；
- Edit theme…：打开项目的主题取色器（§8.2）；
- Pin project / Unpin project：固定后，没有打开的标签时也显示项目行；
- New file / New folder：在项目根目录新建；
- New thread：在这个项目里新建线程；
- Reveal in Finder；
- Open in terminal：新建终端标签，工作目录是项目根；
- Close all tabs；
- Remove project：从 `mounts.json` 移除，不动磁盘。它的标签不关掉，归到 Other。

## 6. 文件树和文件操作

### 6.1 右栏

右栏保留 RFC 0003 的三段：项目文件树、大纲、反向链接。

文件树仍然跟随当前标签：

- 当前标签是项目里的文件，就显示那个项目，并展开到当前文件；
- 当前标签是文件夹页，就显示目录所在的项目，并展开到这个目录；
- 当前标签在 Other，见 §6.3。

文件树段的标题是项目名，点它弹出项目列表，可以临时切到别的项目浏览。切换标签以后回到跟随。

### 6.2 文件操作

文件树里的右键菜单，以及文件夹页卡片上的同样菜单：

| 操作 | 规则 |
|---|---|
| New file、New folder | 在选中的目录里新建，名字就地输入 |
| Rename | 就地改名；改名后，打开它的标签跟着改路径 |
| Move | 拖到另一个目录；跨项目可以拖；打开它的标签跟着改路径和项目 |
| Delete | 移到废纸篓，不做永久删除；打开它的标签关掉 |
| Duplicate | 同目录下复制一份，名字加 ` copy` |
| Copy path、Copy relative path | |
| Reveal in Finder | |
| Open in terminal | 工作目录是这个目录 |

- 重名时提示，不覆盖。
- 这些操作也是 CLI 命令，AI 可以调；现有的 CLI 移动和删除沿用这套规则。

### 6.3 Other 里的文件

当前标签是项目外的文件时：

- 右栏的文件树显示文件所在的目录，只显示那一层，可以向下展开，不能向上；
- 段的标题旁边有「Add as project」按钮，点了就把这个目录加成项目（§5.1），标签随之归过去。

### 6.4 隐藏

- `.git` 不显示。
- `.gitignore` 里的文件在文件树里显示为浅色，搜索和 Omnibox 默认不搜它们。

### 6.5 文件夹页

每个目录都有一个概览页，叫文件夹页，用卡片显示目录里的内容。项目主页（§5.2）是项目根目录的文件夹页。

参照 Quiet.md（`~/Projects/quiet-md-ref`，MIT，Rust + GPUI）：它的主页和每个文件夹都是这种页面。实现见 `src/home.rs`、`src/home_folder.rs`、`src/folders.rs`。

**打开**

- 文件夹页是一种标签，地址是 `folder:<绝对路径>`。按 §4.1 归到目录所在的项目，项目外的进 Other。
- 右栏文件树里，点目录的名字：
  - 打开这个目录的文件夹页；已经有这个目录的标签，就切过去；
  - 同时在树里展开它；
  - 和在文件树里点文件一样，打开的是新标签。
- 点名字左边的箭头，只展开或折叠，不打开页面。Quiet.md 点文件夹时也是同时打开页面、在树里展开（`folders.rs` 的 `open_folder`）。
- 在文件夹页里点目录卡片或面包屑，就在同一个标签里进入那个目录，标签的前进、后退跟着走。新进入的目录从顶部开始显示。
- 所有文件夹页共用一个卡片/列表设置，进入子目录时沿用父目录的视图（Quiet.md 的 `view_switch`）。

**顶栏**

- 左边是面包屑：`项目名 › 目录 › 子目录`，每一段都能点。项目外的目录，面包屑从这个目录开始，旁边有「Add as project」（§6.3）。
- 右边依次是：
  - New file、New folder：建在当前显示的目录里；
  - 视图切换（卡片 / 列表）；
  - `⋯`：在项目根是项目菜单（§5.3），在其他目录是 §6.2 的目录菜单。

**卡片视图**（默认）

- 子目录排在前面，然后是文件。默认按名字排序，可以改成按修改时间排。
- 文件卡片的缩略图是文件开头部分按真实样式渲染后缩小，只用来看，不能选中、不能点里面的链接。Quiet.md 的做法是同一套文档渲染乘 0.28 的比例，卡片宽高比 236:264。不同类型的文件：
  - Markdown：渲染后的开头，包括标题、列表、表格、图片；
  - 代码：前 30 行左右，带语法高亮；
  - 图片：图片本身；
  - 其他：文件类型图标和文件名。
- 卡片下方是文件名。目录卡片是一个文件夹图形，里面露出前几个文件的缩略图。
- 点文件卡片，在本项目里打开这个文件的标签；点目录卡片，进入那个目录。
- 方向键移动选中的卡片，回车打开。右键菜单和文件树的右键菜单相同（§6.2）。
- 把卡片拖到目录卡片上就是移动文件（§6.2 的 Move）。
- 卡片列数按宽度计算，窗口变窄时少放几列。
- 目录里有 `README.md` 时，它的卡片排在最前面。
- `.gitignore` 里的目录（`node_modules`、`target` 这类）显示为浅色，排在最后。

**列表视图**

- 一行一个条目，列为名字、修改时间、大小。点列头排序。

**性能**

- 只渲染可见的卡片。
- 缩略图按「路径 + 修改时间」缓存。
- 每个文件最多读开头 64 KB。

## 7. AI

只定基本形态。批注栏问答见 §12。

### 7.1 接入

- 主 AI 是外部 agent，不用 ACP 接入。候选是 dim，接入方式由 RFC 0007 定，依据见调研 `docs/research/lsp-agent/README.md` §3.6。
- 给 agent 的工具就是现有的 CLI 命令（`open`、`read`、`search`、`files` 等），加上一段提示词。不另做一套工具。

### 7.2 线程

- 一个线程就是一个 Chat 标签，属于一个项目：
  - 在哪个项目里新建，就属于哪个项目；
  - 在 Other 里新建的属于 Other。
- 新建的入口：项目菜单的 New thread，Omnibox 的 `New thread`，新标签页（起始页）里的输入框。
- 线程存在配置目录下，记录所属项目和推送过的原文。
- 关掉的线程不丢：在项目主页的线程列表和 Omnibox 里能找到，再打开。

### 7.3 推送

AI 调 `open` 打开原文时：

1. 原文作为新标签打开，插在线程标签的后面，归到原文所属的项目（§4.1）。标签行上标出「由哪个线程打开」。
2. 如果线程正显示在内容区：
   - 第一次推送时，线程和原文组成分屏，线程在左；
   - 之后的推送替换分屏右边那张卡片显示的标签，被替换的标签留在列表里。
3. 如果线程不在内容区，不抢焦点，只在线程的标签行上显示新推送的数量。
4. 线程里每次推送留一张卡片，写着打开了什么，点它就切到那个标签。

### 7.4 选中提问（基本形态）

- 在代码、Markdown、网页标签里选中文字，弹出浮动条，有两个按钮：
  - Ask：输入问题，连同引用发给线程；
  - Add to thread：只把引用加进线程的输入框。
- 引用的格式是原文逐行引用，再加一行来源：文件写 `— path:L12-30`，网页写 `— 标题 — URL`。
- 发给哪个线程：这个项目最近用过的线程，没有就新建一个；线程不在内容区时，在分屏右边打开它。

## 8. 主题

对齐 Zen 的做法：外壳按项目上色，内容不上色。

### 8.1 亮暗

全局一个开关：Light、Dark、System。不跟着项目变。

### 8.2 项目主题

每个项目一个主题，取代 `Mount.Color`：

```json
{ "colors": ["#f76b15", "#d6409f"], "intensity": 0.5, "texture": 0.3 }
```

- `colors`：1 到 3 个颜色。第一个是主色，用在项目行的点、强调色和 ACard 的 accent 上。
- `intensity`：0 到 1。外壳底色是把颜色层叠在中性底色上：
  - 中性底色：暗色 `#131313`，亮色 `#ffffff`；
  - 颜色层的不透明度在 0.2 到 0.88 之间，按 `intensity` 的平方变化（照 Zen 的 `layerAlpha`）。
- `texture`：颗粒纹理的强度，0 是关。
- 文字色：主色往黑或往白混 12%，按对比度决定用深字还是浅字（照 Zen 的 `titleColors` 和 `shouldBeDarkMode`）。
- 默认值：新项目从 8 个预设色里按名字取一个，`intensity` 0.5，`texture` 0。
- Other 和起始页用中性底色，不叠颜色。

取色器在项目菜单的 Edit theme… 打开，一个浮层，包括：

- 色盘，最多 3 个点；
- 配色规则：互补、分裂互补、类似色、三角、自由；第 2、3 个点按规则自动摆；
- 预设色；
- 强度滑块；
- 纹理滑块；
- 全局亮暗开关。

### 8.3 内容卡片

卡片用中性色，不混入项目颜色：亮色白底，暗色近黑。具体色值跟 ACard 的 token 走。

### 8.4 编辑器配色

编辑器和终端的语法配色单独选，继续用 Zed 主题文件（RFC 0004 的编辑器部分）。

### 8.5 取消界面主题文件

RFC 0004 的界面主题文件（色板加语义 token）不再保留。界面颜色由「全局亮暗、项目主题、ACard 的 token」三者算出。

### 8.6 要先确认的

- macOS 侧栏半透明（vibrancy）：MyGo 是否支持。
- 颗粒纹理：用噪声着色器画，MyGo 是否支持。

两者都不支持时，先不做，`texture` 字段保留。

## 9. 起始页和 Omnibox

**起始页**（新标签页）：

- 中间是 Omnibox 的输入框；
- 下面是三列：项目（含 Add project…）、最近打开的文件、最近的线程。

**Omnibox** 在 RFC 0003 的合并模式上加：

- 文件结果先列当前项目的，再列其他项目的；
- 线程：按标题搜；
- 新命令：`New thread`、`Add project…`、`Edit theme…`。

## 10. 存储

项目还没有用户，格式直接换，不写迁移。

| 文件 | 内容 |
|---|---|
| `mounts.json` | 每个项目：路径、显示名、主题（§8.2）、是否固定、顺序 |
| `session.json` | Tab group 和其中的标签、每个项目下的标签和固定标签、每个项目分组的折叠状态 |
| 线程 | 配置目录下单独存放，每个线程有所属项目、消息和推送记录；格式在实现时定 |
| `appearance.json` | 全局亮暗、编辑器配色 |

## 11. 按推荐先定、待你确认的

1. 项目行只在有打开的标签或被固定时显示（§3）。
2. 网页按打开来源归项目（§4.1）。
3. 每个目录都有 Quiet.md 式的文件夹页，项目主页是根目录那一页；页面自己不带文件树，文件树只在右栏（§5.2、§6.5）。
4. 取消界面主题文件，只保留项目主题加全局亮暗（§8.5）。

## 13. 分步实施

每一步单独提交，都过 native 的全部门禁，并截图核对。

1. 名词和命令改名：`Add folder` → `Add project…`，标签文件夹 → Tab group。
2. `mounts.json` 新格式：显示名、主题、固定、顺序。项目菜单（§5.3）。
3. 侧栏的项目分组和标签归位（§3、§4）。`session.json` 换成新格式。
4. 文件操作（§6.2）和 Other（§6.3）。
5. 文件夹页和项目主页（§6.5、§5.2）。
6. 主题（§8）。依赖 RFC 0005 的 ACard token。
7. AI：线程、推送、选中提问（§7）。接入方式等 RFC 0007。

每一步的代码放进 §14 列出的插件。第 4 步新建 `filemenu`，第 5 步新建 `folderpage` 和 `git`。`icons`、`fileicons`、`pagepreview` 不依赖其他步骤，可以先做。

## 14. 插件划分

依据：

- `native/AGENTS.md`：一个功能一个插件，照 dsh 的插件清单那样拆。
- TS 版已经拆成内置插件的功能（`apps/web/builtin/`、`apps/web/builtin/CorePlugins.ts`），native 照 TS 拆。

### 14.1 新插件

| 插件 | 内容 | 依据 |
|---|---|---|
| `folderpage` | 文件夹页和项目主页（§5.2、§6.5）。是一种标签类型，地址是 `folder:<绝对路径>` | 查看器都是标签类型（AGENTS.md）。TS 版没有这个功能，要新做 |
| `pagepreview` | 鼠标悬停在链接上时，弹出目标文件的预览。阅读视图里直接悬停就弹，编辑器里要按住 Cmd | TS 的 `PagePreview.ts`，默认值照它的 `DEFAULT_HOVER_SOURCES` |
| `filemenu` | 文件和目录的右键菜单（§6.2），文件树、文件夹页、标签头都用这一个 | TS 的 `workspace-file-menu`：订阅 `file-menu`、`files-menu` 事件，往菜单里加操作 |
| `git` | 项目主页的分支和未提交改动数（§5.2），以及文件树里改动文件的标记 | TS 的 `builtin/git/` 是独立插件 |
| `icons` | 图标注册表：按名字取图标，插件可以注册自己的图标 | TS 的 `ui/Icon.ts`：`addIcon`、`getIcon`、`getIconIds`、`setIcon` |
| `fileicons` | 文件图标主题（pierre、zed）：按文件名给出图标和颜色 | 现在是 `native/internal/fileicon`，主题选项在 `appearance` 里，还不是插件 |

### 14.2 图标

- 现在 native 的图标分在三处，没有按名字注册的入口，插件和命令引用不了别的插件的图标：
  - acard-ui 的 `icon`：Lucide 图标；
  - `native/ui/icon`：acard-ui 还缺的 Lucide 图标；
  - `native/internal/fileicon`：文件图标。
- `icons`：Lucide 图标从 acard-ui 取。acard-ui 还没有的，暂时从 `native/ui/icon` 取，补进 acard-ui 以后删掉。
- `fileicons`：把 `internal/fileicon`，以及「File icon theme」「Show file icons」两个设置项搬进来。文件树、标签、快速切换、搜索、文件夹页都从它取文件图标。
- 网站图标由 `web` 插件取。TS 的 web viewer 也是自己监听 `page-favicon-updated` 拿图标的。
- `tabtypes` 现在每种标签类型只有一个图标（`Icon *ui.SVG`）。改成可以按标签地址给图标：
  - 文件：取自 `fileicons`；
  - 网页：网站自己的图标，还没取到时用地球图标；
  - Chat、文件夹页、起始页：取自 `icons`。

### 14.3 已有插件的分工

| 插件 | 本 RFC 里归它的 |
|---|---|
| `workspace` | 侧栏的标签列表、按项目分组和标签归位、Tab group、固定标签、关闭和撤销关闭（§3、§4）；起始页（§9） |
| `project` | 项目的添加、改名、排序、固定、移除，项目菜单（§5.1、§5.3），Add as project（§6.3）；文件操作的 CLI 命令（现有的在 `cli.go`） |
| `fs` | 文件操作的执行。删除是移到废纸篓（现有的 `trash.go`），撤销提示由发起删除的 `filemenu` 弹出 |
| `filetree` | 右栏的文件树，以及 Other 里文件所在的目录（§6.1、§6.3）。右键菜单交给 `filemenu` |
| `outline` | 大纲，标出正在读的章节 |
| `backlinks` | 反向链接，没有时显示空状态 |
| `chat` | 线程、推送、选中提问（§7） |
| `omnibox` | §9 新增的结果和命令 |
| `appearance` | 亮暗和主题（§8） |

- 起始页的三列由 `workspace` 开一个 slot，项目、最近文件、最近线程分别由 `project`、`workspace`、`chat` 注册。
- 拼音全拼和首字母匹配放进 `native/internal/fuzzy`，Omnibox、快速切换、搜索一起用。
